## Кнопка с шестерёнкой и окно настроек

Мод, объявляющий настройки или что-то рисующий, получает **кнопку с шестерёнкой** на вкладке **Mods**, слева от стрелок порядка загрузки. Кнопка открывает **окно настроек** мода - окно с названием мода. У мода без настроек и без рисования шестерёнки нет. Собственных вкладок у модов нет.

В окне сначала показаны **объявленные настройки** (их рисует игра по вашему `mod.json`), а затем то, что добавляет ваша **функция рисования**. Можно использовать любой из способов или оба сразу.

## Объявленные настройки - без кода

Перечислите настройки в `mod.json`. Игра нарисует виджеты, запомнит значения и восстановит их при следующем запуске.

```json
{
  "id": "damage-scale",
  "name": "Damage scale",
  "version": "1.0",
  "api": "1.0",
  "touches_gameplay": true,
  "script": "scripts/main.lua",
  "settings": [
    { "key": "scale", "type": "number", "default": 2.0, "min": 0.5, "max": 10, "step": 0.5,
      "label": { "en": "Damage multiplier", "ru": "Множитель урона" },
      "tooltip": { "en": "Applied to every weapon." } },
    { "key": "infinite", "type": "bool", "default": false, "label": { "en": "Infinite ammo" } }
  ]
}
```

Каждой настройке нужны `key` (её имя в скрипте), `type`, `default` и `label` как минимум с английским текстом.

## Типы настроек

| Тип | Виджет | Значение по умолчанию | Примечания |
|---|---|---|---|
| `bool` | флажок | `true` или `false` | |
| `int` | ползунок (поле перетаскивания без диапазона) | целое число | Необязательные `min`, `max`, `step`; значения «прилипают» к шагу. |
| `number` | ползунок (поле перетаскивания без диапазона) | любое число | Те же параметры. |
| `choice` | выпадающий список | один из вариантов | `choices` - список строк. |
| `text` | текстовое поле | строка | Не больше 1024 байт. |

Другие необязательные поля: `tooltip` (текст при наведении) и `restart_required: true` (отмечает настройку, которая действует только после перезапуска).

Что игра обеспечивает даже для вручную правленых файлов: сохранённое значение неверного типа или неизвестный вариант заменяется значением по умолчанию; числа вне диапазона обрезаются. **Ваш скрипт никогда не увидит недопустимого значения.**

## Перевод подписей

`label` и `tooltip` - объекты, где ключ - код языка. `en` обязателен для подписей; другие языки необязательны, и игра использует английский, если перевода нет.

```json
"label": { "en": "Damage multiplier", "ru": "Множитель урона", "de": "Schadensfaktor" }
```

Название самого мода можно перевести через `names` в `mod.json`: `"names": { "ru": "Множитель урона" }`.

## Использование настроек в скрипте

```lua
local scale = settings.get('scale')          -- чтение
settings.set('scale', 3.0)                   -- запись (обрезается по диапазону, сохраняется)

on('on_settings_changed', function(e)        -- настройка изменена в меню
  log.write('changed: ' .. e.key)
end)
```

```js
const scale = settings.get('scale');
settings.set('scale', 3.0);
on('on_settings_changed', (e) => log.write(`changed: ${e.key}`));
```

- `settings.get` возвращает `nil`/`null` для неизвестного ключа; `settings.set` возвращает `false` и ничего не меняет для неизвестного ключа или неверного типа.
- `on_settings_changed` приходит в игровом потоке в начале **следующего шага игры**, поэтому значение, изменённое в меню, доходит до скрипта примерно через шаг. Пока ползунок тянут, значение сохраняется и объявляется **один раз, когда перетаскивание закончилось**.
- Применяйте настройки один раз при старте **и** в `on_settings_changed`:

```lua
local function apply() uc.weapon(0).damage = 10 * settings.get('scale') end
apply()
on('on_settings_changed', apply)
```

## Где сохраняются значения

В `config.json` рядом с `uc.exe`, в разделе `mods.<ваш id>.settings`. Игрок может сбросить настройки мода, удалив эту часть. Настройки сохраняются по id мода, поэтому **не меняйте `id` опубликованного мода**: игроки потеряют свои значения.

## Собственное окно

Зарегистрируйте **одну функцию** через `ui.draw`. Игра вызывает её каждый кадр, пока открыто окно настроек, после объявленных настроек:

```lua
ui.draw(function()
  ui.text('Player 1')
  if ui.button('Heal') then uc.player(1).damage = 0 end
  ui.same_line()
  ui.tooltip('Sets the damage meter to zero')
end)
```

Виджеты работают только **внутри** функции рисования. У функции бюджет 4 мс на кадр; ошибка или превышение считаются сбоем ([лимиты](lua.md#лимиты)). Рисование идёт в потоке меню, поэтому это единственное место, где **вызовы кода игры** из игрового API (`uc.guest.call`, `uc.game.select_weapon`) не работают; обычное чтение и запись работают.

DLL рисует прямо через Dear ImGui ([Нативные DLL](native-dll.md#рисование-через-imgui)).

## Виджеты

| Виджет | Смысл |
|---|---|
| `ui.text(text)` | Простой текст. |
| `ui.button(label)` | Кнопка. Возвращает `true` в кадре, когда её нажали. |
| `ui.checkbox(label, value)` | Флажок. Возвращает новое состояние. |
| `ui.slider_int(label, value, min, max)` | Целочисленный ползунок. Возвращает новое значение. |
| `ui.slider_float(label, value, min, max)` | Дробный ползунок. Возвращает новое значение. |
| `ui.combo(label, selected, items)` | Выпадающий список; `selected` - индекс с нуля, `items` - список строк. Возвращает новый индекс. |
| `ui.input_text(label, value)` | Текстовое поле. Возвращает новый текст. |
| `ui.color_edit(label, rgba)` | Выбор цвета, четыре числа от 0 до 1. Возвращает новые четыре числа. |
| `ui.separator()` | Горизонтальная линия. |
| `ui.same_line()` | Следующий виджет на той же строке. |
| `ui.collapsing_header(label)` | Сворачиваемый заголовок. Возвращает `true`, пока открыт (содержимое рисуйте только тогда). |
| `ui.tooltip(text)` | Подсказка для только что нарисованного виджета. |

Виджеты различаются по подписи **внутри вашего мода**, поэтому разным виджетам давайте разные подписи.

## Хранение значений виджетов

Функция рисования выполняется каждый кадр; **сами виджеты значения не помнят**. Вы передаёте текущее значение и получаете новое, храня его в собственной переменной:

```lua
local boost, mode = 1.0, 0

ui.draw(function()
  boost = ui.slider_float('Boost', boost, 0.5, 3.0)
  mode  = ui.combo('Mode', mode, { 'Slow', 'Normal', 'Fast' })
  ui.text('Mode ' .. mode .. ', boost ' .. boost)
end)
```

Переменные теряются при перезапуске мода. Если значение нужно помнить, сделайте его **объявленной настройкой** и записывайте через `settings.set`.

## Полный пример

Мод с одной объявленной настройкой, переключателем, управляемым ею, и окном с живой информацией.

`mod.json`

```json
{
  "id": "immortal",
  "name": "Immortal",
  "version": "1.0",
  "api": "1.0",
  "touches_gameplay": true,
  "script": "scripts/main.lua",
  "settings": [
    { "key": "player1", "type": "bool", "default": true, "label": { "en": "Player 1 cannot be hurt" } },
    { "key": "player2", "type": "bool", "default": false, "label": { "en": "Player 2 cannot be hurt" } }
  ]
}
```

`scripts/main.lua`

```lua
local function apply()
  uc.player(1).invulnerable = settings.get('player1')
  uc.player(2).invulnerable = settings.get('player2')
end
apply()
on('on_settings_changed', apply)

ui.draw(function()
  local p = uc.player(1)
  if not p.present then ui.text('not in a mission') return end
  ui.text(string.format('Damage meter of player 1: %.1f of 50', p.damage))
  if ui.button('Heal now') then p.damage = 0 end
end)
```

## Лимиты

- 4 мс на вызов рисования; 1024 байта для настройки типа `text`.
- Окно модальное: пока оно открыто, остальным меню пользоваться нельзя.
- Виджеты работают только внутри функции рисования.

## Устранение неполадок

| Проблема | Вероятная причина и решение |
|---|---|
| Нет кнопки с шестерёнкой | Мод не объявляет настроек и не регистрирует `ui.draw`; либо мод выключен. |
| Значение в игре не меняется | Вы прочитали настройку один раз при старте; применяйте её ещё и в `on_settings_changed`. |
| Ползунок двигается, а скрипт получает значение с запозданием | Так задумано: `on_settings_changed` приходит на следующем шаге игры. |
| Окно мерцает или виджет «не держится» | Храните значение в переменной и возвращайте его каждый кадр ([Хранение значений виджетов](#хранение-значений-виджетов)). |
| Настройки пропали после обновления | Изменился `id` или `key`. Сохраняйте оба стабильными между версиями. |
