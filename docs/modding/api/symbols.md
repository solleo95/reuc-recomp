## `lookup`

`uc.symbols.lookup(name)` returns `int|null`

Status: **implemented**, since API 1.0.

Guest address of a named symbol, or null.

- `name` (`string`): Symbol name, e.g. 'OSInit'.

Lua:

```lua
local addr = uc.symbols.lookup('OSInit')
```

JavaScript:

```js
const addr = uc.symbols.lookup('OSInit');
```

## `name_of`

`uc.symbols.name_of(address)` returns `string|null`

Status: **implemented**, since API 1.0.

Name of the symbol at exactly this address, or null.

- `address` (`int`): Guest address.

Lua:

```lua
local name = uc.symbols.name_of(0x80258AE8)
```

JavaScript:

```js
const name = uc.symbols.name_of(0x80258AE8);
```
