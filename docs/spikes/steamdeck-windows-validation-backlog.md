## Правило пополнения

После каждого сохранённого улучшения добавить отдельную строку: точный diff/файлы, исходная и новая сборки с SHA256, сцена и настройки, фиксированная работа, средний/Max/min FPS, p99/худший кадр, проверки точности, ограничения измерения и статус Windows. Сохранять отдельные бинарники; не объединять несколько новых изменений до их раздельной оценки.

При возврате к Windows: для каждого применимого изменения проверить корректность и чередующийся A/B с подходящим PGO, затем Max и pacing при 1×. Подтверждённую регрессию исключать для Windows. Нейтральный или неопределённый результат явно отмечать. После отдельных проверок сравнить итоговый набор.

Исторические Deck-замеры с cap90 и новые тесты без лимита сравнивать раздельно. Для новых живых тестов использовать полные окна 1× внутри записанных retrace-границ; смешанные x8→1 пики к игровому Max не относить.
