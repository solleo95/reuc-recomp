# enemy

_Generated by scripts/gen_mod_api.py from modding/api/uc_api.json. Do not edit._

One enemy, addressed by the id uc.enemies.list() gives (uc.enemy(10)). Only zombies are supported in this version; another id or an actor of another kind is an error. Ids are valid until the zombie leaves the scene.

| Member | Kind | Type | Status | Since |

| `hp` | read/write | `float` | implemented | 1.1 |
| `alive` | read | `bool` | implemented | 1.1 |
| `head` | read | `bool` | implemented | 1.1 |
| `position` | read/write | `array<float>` | implemented | 1.1 |

## `hp`

`uc.enemy(id).hp` (`float`, read/write)

Status: **implemented**, since API 1.1.

Health: zombies start with 10 to 30 and lose the weapon's damage per hit; 0 or less is dead (the actor stays in the scene until the wave ends). -1000 to 100000.

Lua:

```lua
uc.enemy(10).hp = 1
```

JavaScript:

```js
uc.enemy(10).hp = 1;
```

## `alive`

`uc.enemy(id).alive` (`bool`, read)

Status: **implemented**, since API 1.1.

True while hp is above 0.

Lua:

```lua
if uc.enemy(10).alive then log.write('up') end
```

JavaScript:

```js
if (uc.enemy(10).alive) log.write('up');
```

## `head`

`uc.enemy(id).head` (`bool`, read)

Status: **implemented**, since API 1.1.

True while the head is on (it comes off with a head shot).

Lua:

```lua
local h = uc.enemy(10).head
```

JavaScript:

```js
const h = uc.enemy(10).head;
```

## `position`

`uc.enemy(id).position` (`array<float>`, read/write)

Status: **implemented**, since API 1.1.

World position [x, y, z] in units of 10 cm, y up. Writing moves the zombie at once; the game moves it on from there.

Lua:

```lua
uc.enemy(10).position = { 0, 0, 0 }
```

JavaScript:

```js
uc.enemy(10).position = [0, 0, 0];
```
