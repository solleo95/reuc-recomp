## Как это работает

Тексты игры лежат в одном файле на язык, `Data\message\mes_<язык>.txtres`: `us`, `en`, `fr`, `ge`, `it`, `jp`, `sp`, `du`. В каждом файле около 2600 **записей**; у каждой записи есть номер (её **идентификатор**, id) и одна или несколько строк текста.

Мод текста перечисляет идентификаторы, которые нужно изменить, и новый текст. Порт берёт собственный файл игры, записывает ваши тексты в **копию** и показывает игре эту копию. Исходный файл не затрагивается.

## Быстрый старт

Переименуем пистолет в HUD.

1. Найдите его id: записи 500, 550 и 553 содержат название «Samurai Edge 2» (см. [Как найти идентификаторы](#как-найти-идентификаторы)).
2. Создайте папку `mods\new-names\text`.
3. Создайте `mods\new-names\text\all.json`:

   ```json
   {
     "500": "Silver Pistol",
     "550": "Silver Pistol",
     "553": "Silver Pistol"
   }
   ```
4. Создайте `mods\new-names\mod.json`:

   ```json
   { "id": "new-names", "name": "New names", "version": "1.0", "api": "1.0" }
   ```
5. Запустите игру, поставьте флажок у мода на вкладке **Mods** и **перезапустите игру** (текст читается один раз при старте). В HUD появится новое название.

## Как найти идентификаторы

Используйте утилиту выгрузки, установленную рядом с игрой:

```bat
tools\dump_text.bat "game\DATA\files\Data\message\mes_en.txtres" --output en-original.json
```

Она записывает весь текстовый файл как JSON ровно в том формате, который использует мод:

```json
{
 "1": "Enter",
 "2": "Pick Up",
 "500": "Samurai Edge 2",
 "681": "This crank with a square point was used\nto open shutters and flood gates."
}
```

Откройте файл в любом текстовом редакторе, найдите слова, которые видите в игре, и запишите id. Затем **удалите записи, которые не хотите менять**, и отредактируйте остальные: файл вашего мода перечисляет только то, что вы меняете.

Английский файл (`mes_en`) читать проще всего. Идентификаторы во всех языках одинаковые, поэтому id можно найти в английском и изменить в том языке, который использует игра.

## JSON-файл

```json
{
  "500": "Silver Pistol",
  "681": "First line\nSecond line"
}
```

- Ключи - **идентификаторы записей**, записанные текстом, без ведущих нулей (`"7"`, а не `"007"`).
- Значения - новый текст. **`\n` начинает новую строку**; число строк записи следует вашему тексту. Запись с двумя строками в оригинале имеет две строки и в выгрузке.
- Пишите файл в **UTF-8**. Конец строки Windows (`\r\n`) читается как `\n`.
- Можно использовать любые символы, которые умеет рисовать шрифт игры; символы, которых в шрифте нет, показываются пустыми или неверными знаками.

## Языки и файлы

В папке `text` мода могут лежать такие файлы:

| Файл | К чему применяется |
|---|---|
| `all.json` | К каждому языковому файлу, который есть в игре |
| `us.json`, `en.json`, `fr.json`, `ge.json`, `it.json`, `jp.json`, `sp.json`, `du.json` | Только к этому языку |

Внутри одного мода сначала применяется `all.json`, затем языковой файл, так что языковой файл может уточнять `all.json`.

**Какой язык использует игра?** Файл выбирается по региону игры: американская игра читает `mes_us`. Поэтому моду для американской игры нужен `us.json` (или `all.json`).

## Плейсхолдеры - знаки процента

В некоторых текстах есть **плейсхолдеры** вроде `%s`, `%d` или `%c`. Игра подставляет вместо них имя или число, когда показывает текст. Например, оригинал может читаться как `Got %s!`.

**В вашем тексте должны быть те же плейсхолдеры в том же порядке.** Игра передаёт часть текстов функции форматирования, а пропавший или лишний плейсхолдер приведёт к падению или мусору. Если запись не совпадает, порт её отклоняет (остаётся оригинальный текст), а вкладка Mods сообщает, какой id и почему.

- Чтобы записать знак процента, удвойте его: `50%% done`.
- Осторожнее с `%`, за которым идут пробел и буква: `100% damage` читается как преобразование `% d`. Пишите `100%% damage`.

## Ограничения длины

- Строка - не больше **2048 байт**, запись - не больше **32 строк**, один файл - не больше **100 000 записей**; изменённый текстовый файл не должен вырасти больше 8 МБ. Текст не может содержать символ NUL.
- Собственные тексты игры - не больше 252 байт в строке и 12 строк в записи. Текстовые окна игры рассчитаны на эти размеры. Текст, сильно превышающий их (длиннее вдвое самой длинной исходной строки или больше чем вдвое по числу строк), всё равно применяется, но вкладка Mods выводит заметку, потому что вместится ли он, можно узнать только в игре.

## Несколько модов

Если два мода меняют один и тот же id, **побеждает мод ниже в списке вкладки Mods**. Вывод консоли игры сообщает `text id N is set by A and B (the last one wins)`; внутри одного мода `all.json` и языковой файл конфликтом не считаются.

Мод может также принести **собственный полный текстовый файл** как `files\Data\message\mes_us.txtres` ([Файлы диска](files.md)). Тогда этот файл становится **основой**, к которой применяются текстовые патчи всех модов (побеждает последний мод, принёсший такой файл).

## Особый случай - локализация со своим алфавитом

Некоторые локализации игры (например, русская, хранящаяся в `mes_us`) показывают свои буквы через кодовые точки шрифта: в файле на самом деле лежит похожий на латиницу текст `&ucmovem` для того, что на экране читается как «Пистолет» местным алфавитом. Выгрузка показывает файл ровно как он есть, и ваш текст должен использовать те же кодовые точки. Если вы хотите перевести такую игру, сначала посмотрите, как выглядят исходные строки в выгрузке, и пишите свои в той же кодировке.

## Когда игра замечает изменения

Игра читает текстовый файл **один раз, при старте**. Поэтому изменению текста нужен перезапуск игры. Если вы меняете текст мода во время игры, порт сразу готовит новый файл, а игра использует его при следующем открытии файла, то есть для текста при следующем запуске.

## Проблемы, о которых сообщает вкладка Mods

Проблемы никогда не останавливают мод: плохая запись пропускается, остальные применяются. Они показаны красным под модом как `text: <файл>: ...`:

| Сообщение | Значение |
|---|---|
| `not valid JSON` | Пропущена запятая, скобка или кавычка. Проверьте файл JSON-валидатором. |
| `must be a JSON object of record ids to text` | Файл должен начинаться с `{`. |
| `id "..." is not a record id` | Ключ - не целое число. |
| `id "007" has leading zeros` | Пишите id без ведущих нулей. |
| `id "..." must be text` | Значение должно быть строкой (в кавычках). |
| `10 ids do not exist in mes_us.txtres (500, 501, ...)` | В файле нет записей с такими id (перечислены первые пять). |
| `the placeholders (%s, %d, ...) must match the original's` | См. [Плейсхолдеры](#плейсхолдеры---знаки-процента). Оригинальный текст остаётся. |
| `much longer than the original text file has` | Текст применён, но может не поместиться в окна. |
| `more than 32 lines`, `a line is longer than 2048 bytes` | Превышены ограничения. |
| `the game has no text file for the language 'xx'` | В игре нет файла для этого языка (в нидерландском файле записей меньше, чем в остальных). |
| `more problems are not listed` | На один мод показывается не больше 20 проблем. |

## Устранение неполадок

| Проблема | Вероятная причина и решение |
|---|---|
| В игре ничего не меняется | Моду нужен **перезапуск** игры. Проверьте и языковой файл: американская игра читает `us`, поэтому один `en.json` там ничего не изменит. |
| Меняются только некоторые тексты | Одни и те же слова хранятся под несколькими id (например, `500`, `550` и `553` для одного названия). Найдите в выгрузке все вхождения. |
| Игра падает при показе текста | Пропущен или лишний плейсхолдер (порт обычно такое отклоняет) либо написан одиночный `%`. |
| Буквы выглядят неправильно | В шрифте нет этих символов, либо локализация использует собственные кодовые точки ([особый случай](#особый-случай---локализация-со-своим-алфавитом)). |
| Текст обрезан или налезает | Он слишком длинный для окна. Сократите его. |
