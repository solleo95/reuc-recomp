# Руководство по моддингу Umbrella Chronicles PC

[English](../en/README.md) · **Русский**

Вы здесь: **Руководство по моддингу** (обзор)

Это отправная точка для всех, кто хочет изменить игру: заменить текстуры, музыку или текст, поправить оружие, написать скрипты или собрать нативные DLL. Здесь объяснено, как вообще устроены моды, и подсказано, какое из тематических руководств читать дальше. Каждое руководство есть на английском и на русском, а файлы в обеих папках называются одинаково.

## Как пользоваться руководством

- Если вы никогда не делали модов, читайте эту страницу с начала, пройдите быстрый старт, а затем откройте тематическое руководство под вашу идею (см. [Какой подход выбрать](#какой-подход-выбрать)).
- Если вы уже знаете, что хотите, переходите сразу к нужному руководству по таблице в разделе [Все руководства](#все-руководства). Каждое руководство самостоятельно и начинается с одного и того же блока навигации: переключатель языка, строка «Вы здесь», содержание, а в конце ссылки на соседние руководства.
- Руководства объясняют, **как делать**. Точный перечень всех полей, функций и значений находится в [техническом справочнике](#технический-справочник); руководства ссылаются на него там, где это важно.
- Примеры написаны на Lua, если руководство не посвящено JavaScript или C++. Всё, что умеет Lua-скрипт, умеет и JavaScript-скрипт ([руководство по Lua](lua.md), [руководство по JavaScript](javascript.md)).

## Быстрый старт - первый мод за пять минут

Сделаем мод, который даёт игроку 1 бесконечные патроны.

### Шаг 1 - создайте папку

Откройте папку, в которой лежит `uc.exe`. Внутри создайте папки `mods\infinite-ammo\scripts` (папка `mods` может уже существовать; если нет, создайте её).

### Шаг 2 - напишите mod.json

Создайте файл `mods\infinite-ammo\mod.json` с таким содержимым:

```json
{
  "id": "infinite-ammo",
  "name": "Infinite Ammo",
  "version": "1.0",
  "api": "1.0",
  "touches_gameplay": true,
  "script": "scripts/main.lua"
}
```

`touches_gameplay` равно `true`, потому что мод меняет ход игры. Без этого флага игра отклонит любое изменение, которое попытается сделать скрипт.

### Шаг 3 - напишите скрипт

Создайте файл `mods\infinite-ammo\scripts\main.lua`:

```lua
uc.player(1).infinite_ammo = true
```

### Шаг 4 - включите мод

Запустите игру. Нажмите **Insert**, чтобы открыть меню, и перейдите на вкладку **Mods**. Ваш мод в списке; поставьте флажок. Он стартует сразу, даже посреди миссии. Снимите флажок, и мод остановится; всё, что он изменил, вернётся на место.

### Шаг 5 - загляните в лог

Откройте `debug\mods.log` рядом с `uc.exe`. Каждая строка, которую скрипт пишет через `log.write('текст')`, попадает туда с идентификатором мода в начале. Там же появляются ошибки. Добавьте в скрипт `log.write('hello')`, нажмите **Reload scripts** на вкладке Mods и снова посмотрите в лог.

Поздравляем, это полноценный мод. Остальные руководства показывают, как сделать намного больше.

## Где что лежит

```
Umbrella Chronicles\              папка с uc.exe
  uc.exe                          игра
  config.json                     настройки игры и модов
  mods\                           ваши моды, по папке (или .zip) на мод
    my-mod\
      mod.json                    описание мода (единственный обязательный файл)
      scripts\                    Lua или JavaScript            -> руководства по Lua / JavaScript
      data\                       патчи данных (JSON)           -> руководство по патчам данных
      textures\                   замены текстур (DDS)          -> руководство по текстурам
      audio\                      замены звука (.ogg/.wav)      -> руководство по звуку
      text\                       замены текста (JSON)          -> руководство по тексту
      files\                      замены файлов диска           -> руководство по файлам диска
      native\                     DLL                           -> руководство по нативным DLL
    .cache\                       создаётся игрой: распакованные zip, сконвертированные звук и текст
  textures\                       базовая папка для замен текстур
  tools\                          извлекатель и конвертер текстур, утилита выгрузки текста
  debug\mods.log                  лог модов
  saves\                          ваши сохранения (сделайте копию перед модами, меняющими игру)
  game\DATA\files\                собственные файлы игры (никогда их не правьте)
  docs\                           эта документация
  mods-examples\                  готовые примеры модов
```

Все пути внутри мода **отсчитываются от папки мода**, в `mod.json` пишутся с разделителем `/` и не могут содержать `..`.

## mod.json на одной странице

`mod.json` - единственный обязательный файл мода. Минимум - пять полей:

```json
{ "id": "my-mod", "name": "My Mod", "version": "1.0", "api": "1.1" }
```

| Поле | Что означает |
|---|---|
| `id` | Уникальное короткое имя: строчные латинские буквы, цифры, `_` и `-`, до 48 символов, начинается с буквы или цифры. Используется в конфиге, логе и кэше. |
| `name`, `version` | Показываются на вкладке Mods. Версии - числа через точку (`1.10` новее, чем `1.2`). |
| `api` | Версия API модов, под которую вы писали мод, `"мажорная.минорная"`. Ставьте `"1.1"`, если используете врагов, события, состояние игры, ввод или вызов функций игры, иначе `"1.0"`. |
| `touches_gameplay` | Поставьте `true`, если мод меняет ход игры. Игра следит за этим: без флага скрипты не могут писать в игру, а патчи данных и хуки отклоняются. |
| `script` | Основной файл на Lua или JavaScript. |
| `native` | DLL ([Нативные DLL](native-dll.md)). |
| `settings` | Настройки, которые может менять игрок ([Настройки и интерфейс](settings-and-ui.md)). |
| `depends` | Другие моды, которые должны быть включены. |
| `audio` | Точки зацикливания для заменённой музыки ([Звук](audio.md)). |
| `author`, `description`, `names`, `game` | Сведения для игроков. |

Полное описание всех полей - в [справочнике по mod.json](../../manifest.md).

## Вкладка Mods

Нажмите **Insert** в игре, чтобы открыть меню, и выберите вкладку **Mods**.

- **Флажок** - мгновенно включает или выключает мод. Если мод не может работать, рядом указана причина (например: неподходящая версия API, нет зависимости, ошибка в `mod.json`).
- **Стрелки вверх и вниз** - перемещают мод в порядке загрузки. Порядок решает, какой мод побеждает, когда два меняют одно и то же.
- **Кнопка с шестерёнкой** - открывает окно настроек мода. Появляется, если мод объявляет настройки или рисует свой интерфейс.
- **Allow native mods** - переключатель, по умолчанию выключенный. DLL-моды работают, только когда он включён и вы подтвердили DLL ([Нативные DLL](native-dll.md), [Безопасность вкратце](#безопасность-вкратце)).
- **Reload scripts** - перезапускает скрипты работающих модов, чтобы проверить правку без перезапуска игры.
- Под каждым модом могут быть серые или красные строки: ход конвертации звука и проблемы с файлами звука и текста.

## Как несколько модов работают вместе

Порядок на вкладке Mods - это **порядок загрузки**. Моды применяются сверху вниз; **побеждает мод ниже**, когда два предоставляют одно и то же.

| Вид | Если два мода предоставляют одно и то же |
|---|---|
| Файлы диска (`files\`) | Используется файл нижнего мода. Вкладка Mods перечисляет все конфликтующие пути. |
| Текстуры (`textures\`) | Побеждает текстура нижнего мода; моды побеждают базовую папку `textures\`. |
| Звук (`audio\`) | Побеждает нижний мод по имени потока. Готовый `.brstm` в `files\` того же мода побеждает его файл из `audio\`. |
| Текст (`text\`) | По идентификатору записи побеждает нижний мод. Консоль игры пишет `text id N is set by A and B`. |
| Патчи данных и скрипты | Побеждает тот, кто задал значение последним. |
| Хуки | Выполняются все, в порядке загрузки. |

Поле `depends` в `mod.json` заставляет игру загружать мод после нужных ему модов и выключать его, когда один из них выключен.

## Жизнь мода - включение и выключение во время игры

Игроки могут включать и выключать моды в любой момент, в том числе посреди боя. Пишите мод с учётом этого:

- **Включение:** скрипт (или DLL) загружается, выполняется `on_load`, затем применяются патчи данных. Игра может находиться в меню или на экране загрузки, поэтому проверяйте `uc.player(1).present`, прежде чем считать, что миссия идёт.
- **Выключение:** выполняется `on_unload`, скрипт уничтожается, хуки снимаются, а **всё, что вы задали через игровой API, возвращается** (переключатели вроде `invulnerable`, значения оружия, патчи данных). Всё своё убирайте в `on_unload`.
- Когда мод включают, выключают или двигают, моды **ниже** него перезапускаются по порядку, чтобы результат совпадал с чистым запуском. Не храните в скрипте состояние, которое нельзя восстановить в `on_load`.
- Заменённые файлы, текстуры, звук и текст появляются, **когда игра в следующий раз их откроет**. Некоторые, например файл текста, читаются один раз при старте, поэтому просите игроков перезапускать игру после изменений ([Файлы диска](files.md#когда-игра-замечает-изменения)).

## Безопасность вкратце

- **Скрипты** (Lua, JavaScript) работают в песочнице: они не могут трогать файлы, запускать программы или обращаться к сети. У них есть ограничения по времени и памяти; скрипт, упавший три раза за сеанс, выключается.
- **DLL** работают с полными правами игрока. Игра отказывается их запускать, пока игрок не включит **Allow native mods** и не подтвердит каждую DLL. Публикуйте DLL, только если без неё не обойтись, и объясняйте, что она делает.
- **Файлы звука** декодируются внутри игры; повреждённый файл может её уронить.
- **Моды, меняющие игру, работают с обычными сохранениями.** Отдельных сохранений для модов нет. Просите игроков делать копию папки `saves`.
- Если что-то пошло не так, запустите игру с `--no-mods`, чтобы работать без модов, либо снимите флажок мода, либо переименуйте его папку.

Подробнее - в [справочнике по безопасности](../../safety.md) и в руководстве [Тестирование и публикация](testing-and-sharing.md).

## Какой подход выбрать

| Идея | Лучший подход | Почему |
|---|---|---|
| «Пусть пистолет бьёт сильнее» | [Патч данных](data-patches.md) | Только числа: кода нет вовсе. |
| «Двойной урон, но множитель меняет игрок» | [Lua](lua.md) с [объявленными настройками](settings-and-ui.md) | Нужны логика и ползунок. |
| «Лечить игрока, когда умирает враг» | [Lua](lua.md) и [события](game-api.md#события) | Реакция на `on_enemy_killed`. |
| «Другая музыка на заставке» | [Звук](audio.md) | Положите `.ogg`; инструменты не нужны. |
| «Перевести игру / переименовать предметы» | [Текст](text.md) | JSON с новыми строками. |
| «HD-текстуры» | [Текстуры](textures.md) | PNG в DDS штатным конвертером. |
| «Заменить 3D-модель или ролик» | [Файлы диска](files.md) | Положите файл в формате игры на нужное место. |
| «Изменить работу обновления оружия» | [Хуки](hooks.md) | Свой код внутри функции игры. |
| «Тяжёлый алгоритм, свой оверлей, вызов Windows» | [Нативные DLL](native-dll.md) | Полная скорость и полные права. |

Если сомневаетесь, начните с самого простого варианта, который справляется: патч данных лучше скрипта, скрипт лучше DLL.

## Словарь терминов

| Термин | Значение |
|---|---|
| **Мод** | Папка (или zip) в `mods\` с файлом `mod.json`. |
| **Игровой API** | Всё, что могут читать и менять скрипты и DLL: объект `uc`, `log`, `settings`, `ui`, `hook`, `on`. |
| **Гостевая система (guest)** | Сама игра. Порт выполняет код игры для Wii, переведённый на ПК; «гостевая память» - память, которую видит игра Wii. |
| **Гостевой адрес** | Адрес в этой памяти, например `0x80400000`. Основная память - от `0x80000000` до `0x817FFFFF` (MEM1) и от `0x90000000` до `0x93FFFFFF` (MEM2). Значения хранятся в big-endian. |
| **Шаг игры** | Одно обновление игры. `on_step` вызывается примерно 30 раз за игровую секунду. |
| **Слот** | Игрок 1 или игрок 2. |
| **Идентификатор записи** | Номер оружия в таблице оружия (0-19) или текста в файле текста. |
| **Раскладка диска** | Структура папок собственных файлов игры (`Data\sound\stream\...`). |
| **Оверлей** | Способ наложить файлы замены поверх файлов игры, не меняя их. |
| **Хук** | Ваша функция, вызываемая, когда игра вызывает свою функцию. |
| **BRSTM** | Формат потокового звука игры. |
| **DDS / BC7** | Формат файла текстуры и его сжатие; то, что выдаёт конвертер текстур. |
| **TRES / txtres** | Формат файла текста игры. |
| **Нативный мод** | Мод с DLL. |
