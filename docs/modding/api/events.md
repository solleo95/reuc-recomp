# events

_Generated by scripts/gen_mod_api.py from modding/api/uc_api.json. Do not edit._

Events are delivered to handlers registered with on(). Handlers run on the game thread (or the menu thread for ui callbacks) under a time budget; an error or an overrun counts as a failure of the mod.

## `on`

`events.on(event, handler)` returns `void`

Status: **implemented**, since API 1.0.

Registers a handler. Several handlers for one event run in registration order.

- `event` (`string`): One of the event names below.
- `handler` (`function`): Called with the event payload.

Lua:

```lua
on('on_step', function() end)
```

JavaScript:

```js
on('on_step', () => {});
```

## `on_step`

`on("on_step", handler)`

Status: **implemented**, since API 1.0.

Once per nominal game frame (the game's own 30 Hz step: about 30 per second of game time, whatever the real step rate): a step shorter than a nominal frame skips it, a longer one runs it up to 4 times. Not delivered while the game is paused. Payload: {}.

Lua:

```lua
on('on_step', function() uc.player(1).magazine = 15 end)
```

JavaScript:

```js
on('on_step', () => { uc.player(1).magazine = 15; });
```
