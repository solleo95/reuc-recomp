# Распаковка текстур Umbrella Chronicles

Утилита выгружает сохранённые в ресурсах игры текстуры в PNG RGBA8 без потери
альфа-канала. Запуск игры не требуется. Используется декодер GX самого порта.

После сборки утилита устанавливается в папку `tools` рядом с игрой:

```bat
"<install dir>\tools\extract_textures.bat"
```

Нужен Python 3.10 или новее. Внешние Python-пакеты не требуются. По умолчанию
вход — `game\DATA`, выход — `TexturesDump\RBUE08` рядом с игрой. Отдельная папка
сохраняет существующий DDS-пак в `Textures\RBUE08`.

По умолчанию выгружаются только уникальные базовые изображения для апскейла:
один PNG на совпадающие размеры и все пиксели RGBA, включая прозрачность.
Mip-уровни и дополнительные варианты имён физически не создаются. Уже выбранные
имена в очищенной выгрузке сохраняются при повторном запуске.

Произвольные вход и выход:

```bat
extract_textures.bat --input "<install dir>\game\DATA" --output "<install dir>\TexturesDump\RBUE08"
```

Входом также может быть один архив или контейнер текстур. Для запуска из исходников:

```bat
python tools\texture_extract\extract_textures.py --input "<install dir>\game\DATA" --output "<install dir>\TexturesDump\RBUE08" --decoder build\tools\texture_extract\uc_texture_decode.dll
```

Обрабатываются U8 (`.arc` и `.rarc`, включая вложенные архивы), TPL с палитрами,
BRRES/TEX0/PLT0, BRFNT/RFNT, BREFT/REFT и IMD5/LZ10 баннеры Wii. Из `main.dol`
и `opening.bnr` извлекаются встроенные контейнеры. Проверяются границы буферов,
размеры, число mip-уровней, палитры и контрольная сумма IMD5. Ошибки попадают в
отчёт и дают ненулевой код завершения.
Ошибка одного вложенного файла или конфликт PNG сохраняются с полным путём
ресурса; остальные корректные файлы архива продолжают обрабатываться. Manifest
сохраняет описание найденной текстуры даже при ошибке записи, с `failed_files`
или `error`.

Файлы получают имена Dolphin `tex1_<ширина>x<высота>[_m]_<XXH64>[_<палитра>]_<формат>.png`.
Хеш берётся из исходных блоков базового уровня, включая заполнение краевых блоков;
хеш палитры — из диапазона используемых индексов. Manifest сохраняет оба варианта
имени, с `_m` и без него: фильтр задаётся во время выполнения. Разные исходные
блоки также могут декодироваться в одинаковое изображение, например из-за
заполнения краевых блоков или неиспользуемых цветов палитры. Такие изображения
достаточно улучшить один раз.

`base_levels[].aliases` содержит все имена, под которыми нужен результат в
готовом паке. `textures[].files` указывает на сохранённый базовый PNG,
`textures[].original_files` — на полный набор исходных имён, включая mip-уровни.
Поле `levels` описывает исходный ресурс. Перед использованием в Dolphin готовые
HD-изображения нужно разложить под соответствующими aliases; новые mipmaps можно
построить из улучшенного базового уровня. Изменять хеши в именах не требуется.

Прежняя полная выгрузка доступна отдельно:

```bat
extract_textures.bat --full
```

Её выход по умолчанию — `TexturesDumpFull\RBUE08`. Этот режим сохраняет исходные
mip-уровни (`_mip1`, `_mip2` и далее) и оба варианта имён Dolphin. Он полезен,
если нужны оригинальные, в том числе вручную подготовленные, mipmaps.

Если заполнение краевого блока ссылается на цвета за пределами сохранённой
палитры, её runtime-хеш неизвестен. Для таких изображений используется
поддерживаемый Dolphin wildcard `$` вместо хеша палитры. Счётчик
`palette_wildcards` показывает такие ресурсы. Все видимые пиксели проходят
обычную строгую проверку индексов декодером.

`extractor_manifest.json` связывает PNG с архивом, внутренним файлом, именем
текстуры, смещением данных, размерами, форматом и mip-уровнями. Он также содержит
счётчики просмотренных файлов и сигнатур и список ошибок. Такой отчёт полезен
для будущего загрузчика замен и для поиска текстур по названию игрового ресурса.

Повторный запуск допускает существующие файлы с тем же содержимым. Изменённые
PNG сохраняются; утилита сообщает конфликт. Служебный manifest обновляется
атомарно при каждом запуске. Для другой версии игры или новой
полной выгрузки используйте новую выходную папку. Оригиналы удобно хранить в
`TexturesDump`, а подготовленный HD-пак — в `Textures\RBUE08`.
Утилита сохраняет существующие файлы в выбранной выходной папке. При смене режима
используйте отдельные папки, чтобы старые файлы не попадали в архив для апскейла.

Выгрузка охватывает сохранённые текстуры поддерживаемых контейнеров. Изображения,
создаваемые игрой во время выполнения (EFB-копии, динамические эффекты), и кадры
видеороликов требуют отдельного захвата.

## Замена текстур в игре

Апскейленные PNG (имена те же, что у выгрузки) конвертирует `tools\uc_texture_convert.exe`: BC7 (mode 6) с полной цепочкой mip-уровней, все потоки, около 30 с на 8183 файла.
По умолчанию вход `raw-textures`, выход `textures`, manifest `TexturesDump\RBUE08\extractor_manifest.json` (рядом с папкой игры); `--input`, `--output`, `--manifest`, `--threads`, `--force` меняют это.
Повторный запуск пропускает файлы, у которых DDS новее PNG. Дополнительные имена одного изображения из manifest получают hard link.

`uc.exe` при старте индексирует `textures\tex1_*.dds` рядом с exe. Когда игра первый раз декодирует текстуру, считается имя Dolphin (XXH64 базового уровня и диапазона палитры, как в экстракторе; `_m` не учитывается). Найденный DDS подменяет пиксели, остальные текстуры не меняются. Нет папки — нет подмены; повреждённый DDS пропускается с сообщением в stderr.
Известные ограничения: рантайм-текстуры (EFB-копии, видео) не заменяются; косвенное текстурирование (indirect) использует размер карты, поэтому подмена карт искажения может сместить эффект.

Описания форматов сверены с первичными исходниками:

- [Dolphin TextureInfo.cpp](https://github.com/dolphin-emu/dolphin/blob/master/Source/Core/VideoCommon/TextureInfo.cpp) — имена и хеширование.
- [libogc tpl.c](https://github.com/devkitPro/libogc/blob/master/libogc/tpl.c) — TPL.
- [RiiStudio TextureIO.cpp](https://github.com/riidefi/RiiStudio/blob/master/source/librii/g3d/io/TextureIO.cpp) — TEX0.
- [NintyFont tglp.cpp](https://github.com/hadashisora/NintyFont/blob/master/formats/RFNT/tglp.cpp) — листы шрифтов.
- [BrawlCrate REFT.cs](https://github.com/soopercool101/BrawlCrate/blob/master/BrawlLib/SSBB/Types/REFT.cs) — текстуры эффектов.

Код разбора написан независимо; декодер пикселей переиспользован из `uc_gx`.
