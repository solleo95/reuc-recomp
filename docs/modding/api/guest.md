Calls into the game's own code. Only from the game's own events: on_step, the game events (on_weapon_fired and the rest) and hook handlers; anywhere else (the settings window) the call is an error. The game's registers are restored afterwards, so the interrupted code does not notice. Needs 'touches_gameplay' like every write.

## `call`

`uc.guest.call(address, args)` returns `int`

Status: **implemented**, since API 1.1.

Runs the game function and returns the value it leaves in r3 (an unsigned 32-bit number; pointers are guest addresses). An address that is not the start of a function is an error, not a crash; a wrong argument is not checked, the game function runs with whatever it is given (a bad pointer can crash the game), and nesting is limited to 4 calls.

- `address` (`int`): Guest address of the first instruction of a translated game function (uc.symbols.lookup gives named ones; most functions have no name).
- `args` (`array<int>`, optional): Up to 8 whole numbers, passed in registers r3 to r10 (negative numbers are two's complement).

Lua:

```lua
local record = uc.guest.call(0x8006C8C8, { 0 })
```

JavaScript:

```js
const record = uc.guest.call(0x8006C8C8, [0]);
```
