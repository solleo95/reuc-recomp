## Как работает оверлей

Игра читает свои файлы из **раскладки диска**, папки `game\DATA\files` вашей установки. Порт эти файлы никогда не меняет. Вместо этого папка `files` мода накладывается **поверх** раскладки диска, как прозрачная плёнка: когда игра просит файл, порт сначала заглядывает в моды. Игра разницы не замечает.

```
mods\my-mod\files\Data\movie\MV_000_0.sfd     показывается игре как    Data\movie\MV_000_0.sfd
```

Путь внутри `files` - в точности путь внутри раскладки диска. Регистр в именах не важен.

## Быстрый старт

1. Найдите нужный файл (см. [Как найти нужный файл](#как-найти-нужный-файл)), например `Data\movie\MV_000_0.sfd`.
2. Создайте такие же папки внутри мода: `mods\my-movie\files\Data\movie\`.
3. Положите туда свой файл под тем же именем.
4. Создайте `mods\my-movie\mod.json`:

   ```json
   { "id": "my-movie", "name": "My opening movie", "version": "1.0", "api": "1.0" }
   ```
5. Запустите игру, поставьте флажок у мода на вкладке **Mods** и дойдите туда, где используется файл (см. [Когда игра замечает изменения](#когда-игра-замечает-изменения)).

## Что лежит в папке игры

`game\DATA\files\Data` занимает около 4 ГБ. Основные папки:

| Папка | Содержимое |
|---|---|
| `bg` | Фоны и геометрия уровней |
| `chara` | Персонажи и враги (архивы с моделями и текстурами) |
| `effect` | Эффекты |
| `event` | Данные событий и сюжетных сцен |
| `HomeButton2` | Замена меню Home на Wii |
| `layout` | Макеты экранов меню и HUD |
| `message` | Тексты (`mes_<язык>.txtres`) и таблицы субтитров (`movie_jimaku*.csvtbl`); см. [Текст](text.md) |
| `movie` | 59 роликов (`.sfd`) |
| `script` | Сценарии сцен и данные эффектов (`.arc`, `.emt`) |
| `sky` | Небо |
| `sound` | Банки звуков (`.brsar`) и потоки в `sound\stream` (`.brstm`); см. [Звук](audio.md) |
| `sysres` | Системные ресурсы: шрифты (`font0..2\*.brfnt`), общие архивы |

Типы файлов, которые вам встретятся:

| Расширение | Что это |
|---|---|
| `.arc` | Архив (формат Wii U8) с моделями, текстурами, скриптами. |
| `.brres` | Ресурс модели, текстуры или анимации. |
| `.brstm`, `.brsar` | Потоковый звук и банки звуков. |
| `.sfd` | Ролик (CRI Sofdec). |
| `.brfnt` | Шрифт. |
| `.txtres`, `.csvtbl` | Тексты и таблицы субтитров. |

Порт не поставляет инструментов для правки этих форматов. Используйте общие инструменты сообщества моддинга Wii для архивов и моделей, а для текстур, звука и текста - соответствующие руководства этой папки.

## Как найти нужный файл

Запустите игру из командной строки с параметром `--log-dvd`:

```bat
uc.exe --log-dvd
```

Консоль печатает строку для каждого файла, который игра **открывает**, и для каждого **чтения**:

```
[dvd] open Data/message/mes_us.txtres
[dvd] read Data/message/mes_us.txtres offset 0 length 257184
[dvd] open Data/sound/stream/00_Title.brstm
```

Сыграйте ту часть игры, которая вас интересует (меню, миссию, ролик), и прочитайте пути из консоли. Так вы точно узнаете, какой файл где используется.

## Правила

- Файл в `files` с **тем же путём**, что у файла игры, **заменяет** его.
- Файл, пути которого нет в игре, **добавляется**; игра может открыть его по имени ([Добавление файлов](#добавление-файлов)).
- Регистр в именах не важен; при создании папок можно свободно использовать `/` или `\`.
- Символические ссылки и junction внутри `files` игнорируются.
- У файла может быть **любая длина**; порт отдаёт его как есть.

## Архивы

Оверлей работает с **файлами целиком**. Если игра хранит много ресурсов внутри одного архива `.arc` и открывает его как один файл, вы заменяете **архив целиком**, а не один файл в нём. Чтобы изменить одну модель внутри архива, распакуйте архив инструментом для архивов Wii, измените модель, упакуйте архив заново и положите новый архив в `files`.

Автоматическая замена отдельных файлов внутри архивов запланирована, но пока недоступна.

## Когда игра замечает изменения

Моды можно включать и выключать во время игры. Порт сразу перестраивает оверлей, но **игра использует его при следующем открытии файла**:

- Файл, который игра **уже держит открытым или загрузила в память** (уровень, играющий сейчас звук), остаётся прежним, пока игра не загрузит его заново, например в следующей области.
- Файл, который игра читает **один раз при старте** (текстовые файлы), требует перезапуска.
- Если файл заменили, пока игра его читает, игра продолжает использовать версию, которую открыла. Поэтому играющий поток не ломается, когда вы включаете или выключаете мод.

Практическое правило для проверки: после изменения мода **перезапускайте игру**, если не уверены, что игра перезагружает файл в проверяемой сцене.

## Конфликты между модами

Если у двух включённых модов одинаковый путь, **побеждает мод ниже в списке вкладки Mods**. Вкладка Mods перечисляет все пути, которые предоставляют два и больше модов, а консоль игры печатает строки `[mods] conflict on ...`. Меняйте порядок модов стрелками, чтобы выбрать победителя.

## Добавление файлов

Новый файл сам по себе ничего не делает: игра открывает только те файлы, о которых знает её код. Добавление файлов полезно, когда их использует другая часть вашего мода: скрипт, хук или заменённый файл, ссылающийся на дополнительный файл по имени.

## Ограничения и риски

- Замена должна быть **корректной для игры**: тот же формат и та структура, которую ждёт игра. Порт проверить это не может. Неверная модель или архив могут уронить игру или показать мусор.
- Замена файла, используемого **при каждом запуске** (системные архивы, шрифты), ломает игру у всех, кто использует мод; проверяйте внимательно и пишите в описании, что вы изменили.
- Ролики декодируются кодом самой игры: `.sfd` должен быть корректным файлом Sofdec такого размера и вида, который принимает проигрыватель игры.
- Файлы игры никогда не меняются. Выключение или удаление мода всё возвращает.

## Устранение неполадок

| Проблема | Вероятная причина и решение |
|---|---|
| Игра игнорирует мой файл | Путь отличается от пути игры (проверьте через `--log-dvd`), либо игра загрузила оригинал до включения мода: перезапустите игру. |
| Игра падает после замены файла | Файл неверен для игры. Удалите его и попробуйте снова с файлом в исходном формате и структуре. |
| Два мода конфликтуют | Посмотрите строки конфликтов и поменяйте порядок на вкладке Mods. |
| Мод как будто ничего не делает, хотя файл на месте | Мод включён? Есть `mod.json`? Папка должна быть `mods\<имя>\files\...` с собственными именами папок игры внутри `files`. |
