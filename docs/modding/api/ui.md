## `draw`

`ui.draw(callback)` returns `void`

Status: **implemented**, since API 1.0.

Registers the function that draws the mod's tab below the declared settings (Lua and JavaScript; a DLL draws through ImGui directly).

- `callback` (`function`): Called every menu frame while the mod's tab is visible.

Lua:

```lua
ui.draw(function()
  if ui.button('Heal') then uc.player(1).damage = 0 end
end)
```

JavaScript:

```js
ui.draw(() => {
  if (ui.button('Heal')) uc.player(1).damage = 0;
});
```
