# hook

_Generated by scripts/gen_mod_api.py from modding/api/uc_api.json. Do not edit._

Callbacks on selected game functions. Only the functions listed under 'Hookable functions' accept hooks (the list grows with releases); each hook point costs nothing while no mod uses it.

| Member | Kind | Type | Status | Since |
|---|---|---|---|---|
| `list` | function | `array<string>` | implemented | 1.0 |
| `pre` | function | `void` | implemented | 1.0 |
| `post` | function | `void` | planned | 1.0 |
| `replace` | function | `void` | planned | 1.0 |

## `list`

`hook.list()` returns `array<string>`

Status: **implemented**, since API 1.0.

Names of the hookable functions.

Lua:

```lua
for _, name in ipairs(hook.list()) do log.write(name) end
```

JavaScript:

```js
for (const name of hook.list()) log.write(name);
```

## `pre`

`hook.pre(name, callback)` returns `void`

Status: **implemented**, since API 1.0.

Runs a callback before the game function. The callback may change the registers it is given (they are written back).

- `name` (`string`): A hookable function name.
- `callback` (`function`): Called before the function runs with a table of its registers: r3..r10 as integers, f1..f8 as floats.

Lua:

```lua
hook.pre('GameWeaponUpdate', function(regs) log.write('r3=' .. regs.r3) end)
```

JavaScript:

```js
hook.pre('GameWeaponUpdate', (regs) => log.write('r3=' + regs.r3));
```

## `post`

`hook.post(name, callback)` returns `void`

Status: **planned**, since API 1.0.

Runs a callback after the game function returned (needs translator support; see hooks.md).

- `name` (`string`): A hookable function name.
- `callback` (`function`): Called after the function returned.

## `replace`

`hook.replace(name, callback)` returns `void`

Status: **planned**, since API 1.0.

Replaces the game function (needs translator support; see hooks.md).

- `name` (`string`): A hookable function name.
- `callback` (`function`): Runs instead of the function.
