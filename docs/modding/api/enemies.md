## `list`

`uc.enemies.list()` returns `array<object>`

Status: **implemented**, since API 1.0.

One object per enemy: { id: int, class: int, x: float, y: float, z: float, hp: float }. Only zombies are listed in this version.

Lua:

```lua
for _, e in ipairs(uc.enemies.list()) do log.write(e.hp) end
```

