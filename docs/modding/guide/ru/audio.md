## Как это работает

Музыка, голоса и звук роликов хранятся в игре как около 1330 **файлов потоков** с именами вроде `Data\sound\stream\00_Title.brstm` (музыка заставки) или `VO_2201003.brstm` (одна реплика). Мод заменяет поток, если положить в его папку `audio` файл с **тем же именем** (без расширения):

```
mods\my-music\
  mod.json
  audio\
    00_Title.ogg          заменяет музыку заставки
    VO_2201003.wav        заменяет одну реплику
```

Пока мод включён, порт в фоне преобразует каждый файл, сохраняет результат в кэше и накладывает его поверх потока игры. Пока преобразование не закончено, продолжает играть оригинал.

Короткие звуки (щелчки кнопок, выстрелы) живут в банках звуков, а не в файлах потоков; так заменить их нельзя.

## Быстрый старт

1. Создайте папку `mods\my-music\audio`.
2. Скопируйте туда свою песню как `00_Title.ogg` (или `.wav`).
3. Создайте `mods\my-music\mod.json`:

   ```json
   { "id": "my-music", "name": "My title music", "version": "1.0", "api": "1.1" }
   ```
4. Запустите игру, нажмите **Insert**, поставьте флажок у мода на вкладке **Mods** и перезапустите игру. На заставке играет ваша песня.

Под названием мода на вкладке Mods во время преобразования показано `converting audio (1 of 1)`, а после - проблемы, если они есть.

## Как найти нужный поток

Потоки лежат в папке данных игры: `game\DATA\files\Data\sound\stream`. Имена не слишком говорящие, но подчиняются шаблонам:

| Шаблон | Что это |
|---|---|
| `00_Title`, `01_Gameover`, `02_Scenario`, `03_Result` | Заставка, конец игры, выбор главы, экран результатов |
| `04_Train_...` и другие пронумерованные имена | Музыка миссий |
| `VO_xxxxxxx` | По одной реплике; моно, маленькие |
| остальные имена | Звук роликов и особая музыка |

Чтобы узнать, **какой поток играет сейчас**, запустите игру из командной строки с параметром `--log-dvd`:

```bat
uc.exe --log-dvd
```

Консоль печатает строку `[dvd] open Data/sound/stream/<имя>.brstm` каждый раз, когда игра открывает поток. Сыграйте нужную сцену и прочитайте имя из вывода.

## Подготовка звукового файла

**Форматы, которые читает порт**

- **Ogg Vorbis** (`.ogg`): моно или стерео, любая частота дискретизации.
- **WAV** (`.wav`): 8, 16, 24 или 32 бита целые либо 32 бита с плавающей запятой; моно или стерео; любая частота.

MP3, FLAC, AAC и больше двух каналов не поддерживаются. Сначала преобразуйте их. Бесплатные **ffmpeg** или **Audacity** делают это одним шагом:

```bat
ffmpeg -i mysong.mp3 -ac 2 -c:a libvorbis -q:a 6 00_Title.ogg
```

(`-ac 2` делает стерео, `-q:a 6` - хорошее качество; для моно-реплики используйте `-ac 1`.)

**Каналы и частота** потока игры фиксированы (в основном моно для голосов, стерео для музыки; 32 кГц или 48 кГц). Порт подгоняет ваш файл сам: стерео для моно-потока сводится в моно, моно для стерео-потока звучит в обоих каналах, частота пересчитывается. Подгонять вручную не обязательно, но лучше всего, если музыка уже стерео, а реплики моно.

**Длина:** файл может быть до 30 минут и 512 МБ.

**Громкость:** порт громкость не меняет. Подгоните файл под громкость оригинала, чтобы он не выбивался.

## Зацикливание музыки

Музыка в игре зациклена: дойдя до конца, она прыгает на **начало петли** и играет дальше. Поток игры играет по кругу от начала петли до самого конца потока, поэтому порт обрезает ваш звук по концу петли.

Петля берётся из первого существующего источника:

1. **`mod.json`:** запись `audio` для потока, в отсчётах **вашего файла**:

   ```json
   {
     "id": "my-music", "name": "My title music", "version": "1.0", "api": "1.1",
     "audio": { "00_Title": { "loop_start": 1000, "loop_end": 900000 } }
   }
   ```

   `loop_end` не включается в петлю (это первый отсчёт после неё). Начало должно быть раньше конца.
2. **Сам файл:** блок `smpl` в WAV (первая петля; большинство аудиоредакторов умеют его записывать) или комментарии Vorbis `LOOPSTART` и `LOOPLENGTH` (либо `LOOPEND`). Для ffmpeg:

   ```bat
   ffmpeg -i song.wav -c:a libvorbis -q:a 6 -metadata LOOPSTART=100000 -metadata LOOPLENGTH=2000000 00_Title.ogg
   ```
3. **Ничего:** поток играет один раз и останавливается.

Чтобы узнать номера отсчётов, откройте файл в редакторе вроде Audacity, выделите петлю и считайте позиции в отсчётах (переключите отображение времени на отсчёты).

Петля, которая не подходит файлу (начало не раньше конца, конец за пределами файла), игнорируется, а вкладка Mods показывает заметку под вашим модом.

## Что порт делает с вашим файлом

1. Декодирует ваш `.ogg` или `.wav`.
2. Пересчитывает частоту до частоты потока (32 000 или 48 000 Гц) и подгоняет каналы.
3. Применяет петлю (обрезает звук по её концу).
4. Сохраняет как несжатый 16-битный поток в `mods\.cache\_audio\<id мода>\`. Файл примерно **в 3,5 раза больше** исходного потока (песня в 16 МБ превращается примерно в 56 МБ). Каждый сконвертированный файл лежит на диске дважды (кэш и копия, накладываемая на игру).
5. Накладывает его на поток игры перед оригиналом.

Результат запоминается. При следующем запуске неизменённый файл заново не преобразуется. Файл считается неизменённым, если совпали его **размер и время изменения**; если вы правите файл так, что оба остаются прежними, обновите время файла или измените его размер.

## Замена потока файлом в формате игры

Если у вас уже есть готовый `.brstm`, положите его в `files\Data\sound\stream\<имя>.brstm` ([Файлы диска](files.md)). `.brstm` в `files\` побеждает файл из `audio\` с тем же именем в том же моде, и вкладка Mods сообщает, что звуковой файл не используется.

## Изменения во время игры

- Игра открывает поток, когда начинает его играть, и **продолжает читать ту версию, которую открыла**. Поэтому играющий сейчас трек остаётся оригинальным, пока не начнётся заново.
- Сконвертированный файл, который игра могла уже открыть, **никогда не заменяется «из-под неё»**. Если вы меняете или удаляете файл в `audio\` во время игры, вкладка Mods сообщает об этом, и изменение вступает в силу при следующем запуске игры.
- Выключение мода возвращает оригинал со следующего открытия потока игрой. Сконвертированные файлы остаются на диске, поэтому повторное включение мгновенно.
- Старые версии изменённого файла удаляются, когда готова новая. Кэш удалённого мода удаляется при следующем запуске игры.

## Ограничения

- Только потоки (музыка, голоса, звук роликов). Звуки из банков и звук видеофайлов так заменить нельзя.
- Имя должно совпадать с существующим потоком. Файл, имя которого не совпадает ни с одним потоком, игнорируется и отмечается на вкладке Mods.
- Для Ogg используется сторонний декодер, рассчитанный на доверенные файлы: повреждённый или вредоносный `.ogg` может уронить игру. Используйте только доверенные файлы и публикуйте файлы, которые сделали сами ([справочник по безопасности](../../safety.md)).

## Устранение неполадок

| Проблема | Вероятная причина и решение |
|---|---|
| Всё ещё играет оригинал | Имя не совпадает (проверьте через `--log-dvd`), преобразование ещё не закончено или поток уже был открыт: перезапустите игру. |
| Вкладка Mods пишет «the game has no stream named ...» | Неверное имя файла. Регистр не важен, но в остальном имя должно совпадать; только буквы, цифры, `_` и `-`. |
| «audio: ...: ignored: the mod's own files/.../x.brstm is used instead» | У вас в `files\` есть `.brstm` с тем же именем. Удалите один из файлов. |
| Вкладка Mods показывает красное сообщение о файле | Файл повреждён или в неподдерживаемом формате (MP3, FLAC, больше двух каналов, WAV с необычным устройством). Сконвертируйте его заново через ffmpeg или Audacity. |
| Музыка не зацикливается или зацикливается не там | Нет сведений о петле: добавьте их в `mod.json` или файл. Проверьте, что номера отсчётов относятся к **вашему** файлу. |
| Файл звучит слишком быстро или медленно | Не должно быть: частота пересчитывается. Если в заголовке самого файла неверная частота, исправьте файл. |
| Диск заполняется | Сконвертированные файлы примерно в 3,5 раза больше исходных. Удалите `mods\.cache\_audio`, чтобы освободить место (при необходимости папка создаётся заново). |
