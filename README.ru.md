## Возможности

### Нативное исполнение и производительность

- **Нативный код, без эмулятора.** Программа игры для PowerPC заранее статически транслируется в нативный код x86-64 и исполняется прямо на вашем процессоре, со своей средой исполнения для Windows и рендерером на Vulkan вместо графического процессора Wii.
- **Высокая производительность и разблокированный FPS.** Готовые лимиты кадров до 240 FPS или вообще без лимита вместо исходных 30. Сборка использует ThinLTO и оптимизацию по профилю (PGO), а самые горячие места Wii SDK заменены нативным кодом.
- Шейдеры и пайплайны прогреваются до старта игры, поэтому компиляция шейдеров не вызывает рывков во время игры.
- Оконный, безрамочный и эксклюзивный полноэкранный режимы, любое разрешение и настраиваемый внутренний масштаб рендера.

### Управление, сделанное для ПК

- **Очень удобное и отзывчивое управление мышью.** Сырой относительный ввод мыши без ускорения и сглаживания, задержка наведения уменьшена, чтобы прицел следовал за рукой. Исходные жесты пульта Wii (нож, QTE, граната) работают на мыши и клавиатуре.
- **Подсказки и промпты на экране показаны иконками мыши и клавиатуры** (и меняются при переназначении клавиш) вместо кнопок пульта Wii.
- Каждое действие можно переназначить в лаунчере, у каждого может быть несколько назначений; поддерживаются кнопки мыши, колесо и сочетания клавиш.
- Основной способ игры — клавиатура и мышь; внутриигровое меню открывается клавишей **Insert** (см. [Внутриигровое меню](#внутриигровое-меню-и-управление)).

### Улучшенная графика

- **Апскейлинг:** NVIDIA **DLSS** (Super Resolution и DLAA, все режимы качества) и AMD **FSR 3.1** (на любой видеокарте). Интерфейс (HUD) рисуется в полном выходном разрешении и остаётся чётким.
- **Генерация кадров:** NVIDIA **DLSS Frame Generation** (2x на RTX 40, до 6x на RTX 50) и **FSR 3.1 Frame Generation** (работает на видеокартах без RTX). HUD из интерполяции исключён. С NVIDIA Reflex для низкой задержки.
- **Трассировка лучей** (видеокарты с поддержкой ray query): трассированные тени от солнца и ламп с собственным шумоподавлением; **DLSS Ray Reconstruction** на видеокартах RTX. Другие трассируемые эффекты в разработке.
- **Нативный вывод HDR** (HDR10), когда в Windows включён HDR.
- **Улучшенные эффекты:** собственный bloom в плавающей точке, ambient occlusion (GTAO), контактные тени, попиксельное освещение, SMAA, анизотропная фильтрация 16x и motion blur — каждый эффект включается отдельно.
- **Необязательный DLSS 5** (Neural Rendering) для поддерживаемых видеокарт NVIDIA. Среда исполнения DLSS 5 не входит в проект и не распространяется с ним: файл `nvngx_dlssnr.dll` вы кладёте рядом с `uc.exe` самостоятельно, и только тогда появляется пункт DLSS 5. По умолчанию выключен.
- Замена текстур на текстуры высокого разрешения (см. [Моддинг](#моддинг)).

- Встроенный **лаунчер на 13 языках**: English, Русский, Deutsch, Français, Español, Italiano, Português, Polski, Українська, Türkçe, 日本語, 한국어, 简体中文.

### Расширенный моддинг

- Моды — это папки в `mods/`, которые можно включать и выключать **прямо во время игры**.
- Можно менять **практически любые ресурсы**: текстуры (DDS), звук (OGG / WAV), тексты и шрифты, любой файл диска, архивы, видео, а также данные оружия и игры без написания кода.
- **Скрипты на Lua и JavaScript** с документированным API игры (игроки, оружие, враги, камера, ввод, события, интерфейс, настройки) и **хуки** на собственные функции игры.
- **Моды в виде нативных DLL** для того, на что скриптов не хватает по скорости или возможностям.
- Примеры модов в [`mods-examples`](mods-examples) (бесконечные патроны, бессмертие, рандомайзер, инспектор, нативная DLL и другие).

См. [Моддинг](#моддинг).

## Системные требования

Порт проверялся только на ПК автора (NVIDIA GeForce RTX 4080, Windows 11), поэтому минимальные требования пока не определены. Что известно:

|                                    |                                                                                            |
| ---------------------------------- | ------------------------------------------------------------------------------------------ |
| **ОС**                             | Windows 10 / 11, 64-разрядная                                                              |
| **Процессор**                      | x86-64 с поддержкой **AVX2** (Intel Haswell / AMD Excavator или новее)                     |
| **Видеокарта**                     | С поддержкой **Vulkan 1.3** и актуальным драйвером                                         |
| **DLSS и DLSS Frame Generation**   | NVIDIA GeForce RTX (генерация кадров 2x на RTX 40, до 6x на RTX 50)                        |
| **FSR 3.1 и FSR Frame Generation** | Любая видеокарта с Vulkan 1.3 — **RTX не нужна**                                           |
| **Трассировка лучей**              | Видеокарта с поддержкой ray query (лаунчер покажет, есть ли она у вас)                     |
| **DLSS 5**                         | Необязательно; видеокарта NVIDIA RTX и среда `nvngx_dlssnr.dll`, которую вы добываете сами |
| **Игра**                           | Собственный образ _Resident Evil: The Umbrella Chronicles_ для Wii, **NTSC-U (`RBUE08`)**  |

> [!NOTE]
> Поддерживается только североамериканский релиз (`RBUE08`). Транслированный код игры привязан к конкретному `main.dol` этого релиза, поэтому версии PAL (`RBUP08`) и японская (`RBUJ08`) работать не будут.

## Установка

### 1. Скачайте порт

1. Откройте [страницу релизов](https://github.com/solleo95/reuc-recomp/releases/latest) и скачайте **`UC-Windows-X.Y.Z.zip`**.
2. Распакуйте архив в папку, где у вас есть право записи (например, `C:\Games\Umbrella Chronicles`; **не** в `Program Files`). Содержимое архива кладётся прямо в эту папку: вы увидите `uc_launcher.exe`, `uc.exe` и несколько DLL.

### 2. Распакуйте образ игры с помощью Wit

В порте нет игры. Он читает файлы игры из папки, куда **вы** распаковываете **свой** образ диска. Для этого нужна программа **Wit** (Wiimms ISO Tools).

**Что нужно:** образ вашего собственного диска версии NTSC-U (`RBUE08`) в формате `.iso`, `.wbfs`, `.ciso`, `.wdf` или `.wia`. (Формат `.rvz` из Dolphin Wit не поддерживает: сначала преобразуйте его в ISO в Dolphin — _правая кнопка на игре → Convert File…_.) Диск можно снять с помощью Wii и homebrew-программ.

**Распаковка:**

1. Скачайте **Wit** для Windows на <https://wit.wiimm.de/wit/> и распакуйте, например, в `C:\Tools\wit`.
2. Откройте **PowerShell** или командную строку в папке с портом (где лежит `uc.exe`) и выполните (подставьте свои пути):

   ```powershell
   C:\Tools\wit\bin\wit.exe extract "C:\Images\Umbrella Chronicles.iso" ".\game"
   ```

   `wit extract` (коротко `wit x`) записывает весь диск в папку `game`. Это занимает около минуты и около 4 ГБ места.

3. Проверьте результат. Должен существовать файл **`game\DATA\sys\main.dol`**. Структура должна выглядеть так:

   ```
   uc.exe
   uc_launcher.exe
   game\
   ├─ DATA\
   │  ├─ files\        (данные игры)
   │  └─ sys\
   │     └─ main.dol
   └─ UPDATE\
   ```

4. _(Необязательно)_ Проверьте, что образ тот самый. SHA-1 файла должен быть `7ed67efe2ba9b0de1cef0bbb2ea157d7a43d7f25`:

   ```powershell
   certutil -hashfile "game\DATA\sys\main.dol" SHA1
   ```

Если вы распаковали игру в другую папку, выберете её в лаунчере на следующем шаге. Выбираемая папка должна быть той, что **содержит `DATA`**.

### 3. Первый запуск и настройки

1. Запустите **`uc_launcher.exe`**. Если лаунчер пишет _«Укажите папку распакованной игры»_, нажмите на поле **Папка игры** и выберите папку из шага 2 (ту, где лежит `DATA`). Зелёная галочка означает, что игра найдена.
2. Выберите язык лаунчера (вверху окна), разрешение и режим окна.
3. Настройте графику. Хорошая отправная точка:
   - **Апскейлер:** DLSS (видеокарта RTX) или FSR (любая видеокарта), режим _Качество_. Без апскейлера игра рисуется в вашем разрешении как есть.
   - **Генерация кадров:** оставьте выключенной, пока игра не будет работать хорошо, потом попробуйте. Выбор генератора сам включает соответствующий апскейлер.
   - **Трассировка лучей, DLSS Ray Reconstruction, HDR:** только если их поддерживает ваша видеокарта; недоступные пункты затенены с объяснением.
   - **Лимит FPS:** лимит определяет и частоту шагов симуляции игры. При генерации кадров отображаемый FPS равен лимиту, умноженному на множитель генератора.
4. Откройте страницу **Управление**, если хотите изменить назначение клавиш.
5. Нажмите красную кнопку **Одиночная игра**, чтобы запустить игру (рядом кнопка **Мультиплеер**).

При **первом запуске** лаунчер выполняет короткую калибровку процессора, а игра компилирует шейдеры и пайплайны, прежде чем показать картинку. Первый запуск дольше, последующие быстрее.

Всё, что вы меняете в лаунчере, сразу сохраняется в `config.json` рядом с `uc.exe`. Сохранения игры лежат в папке `saves`. Не запускайте игру из места, недоступного для записи.

Большую часть графических настроек можно менять и **в самой игре**: нажмите **Insert**.

### 4. Обновление

Лаунчер проверяет новый релиз при запуске и предлагает **Обновить** или **Позже**. После согласия он скачивает архив, проверяет его, перезапускается и заменяет файлы. `config.json`, `saves`, `mods`, `textures`, `game` и ваши собственные файлы сохраняются. Перед обновлением закройте игру. Подробнее: [docs/releasing.md](docs/releasing.md).

## Внутриигровое меню и управление

- **Insert** открывает внутриигровое меню поверх игры: графика и эффекты (сразу, без перезапуска игры), DLSS / FSR и генерация кадров, DLSS 5, назначение клавиш и вкладка **Mods**, где моды включаются и выключаются во время игры. Повторное нажатие Insert закрывает меню.
- Прицеливание делается мышью, основные действия вынесены на кнопки мыши и колесо; полный список и переназначение находятся на странице **Управление** лаунчера и во внутриигровом меню.
- **Alt** освобождает курсор мыши в оконном режиме. **Esc** — пауза.

## Мультиплеер (сетевая кооперативная игра)

> [!WARNING]
> **Мультиплеер сырой и мало протестирован.** Возможны проблемы с подключением, рассинхронизация и неприятные моменты после скачка задержки. Пожалуйста, сообщайте о том, что видите, на [Discord](https://discord.gg/njy2CqecyY) или в [Issues](https://github.com/solleo95/reuc-recomp/issues). Технические заметки и известные проблемы: [docs/testing/netplay.md](docs/testing/netplay.md) (на английском).

Двое игроков играют вместе по сети. По сети передаются только ввод игроков и контрольные суммы; каждый компьютер выполняет всю игру целиком и рисует свою картинку со своей частотой кадров.

**Прежде чем начать**

- **У обоих игроков должна быть одинаковая версия порта** (один и тот же релиз, лаунчер обновлён) **и одинаковые данные игры** (`RBUE08`).
- Подключившийся игрок играет на **временной копии сохранений хоста**; личные сохранения обоих игроков не меняются.
- **Моды в сетевой игре отключены.**
- **Пароля и шифрования нет.** Играйте только со знакомыми и сообщайте свой адрес только им.

### Создание игры (хост)

1. В лаунчере нажмите **Мультиплеер**, затем **Создать сервер**.
2. В окне показаны два адреса, у каждого есть кнопка **Копировать IP:порт**:
   - **Интернет** — ваш внешний IP-адрес и порт. Лаунчер пытается открыть порт на роутере **автоматически (UPnP)**; в окне видно, получилось ли.
   - **Локальная сеть** — для друга в той же домашней сети. Если у вас несколько сетевых адаптеров, выберите нужный в списке.
3. Отправьте адрес другу (Интернет-адрес — другу в другом месте, локальный — другу в вашей сети) и ждите. Игра сама запустится у обоих, как только соединение будет установлено.

Порт по умолчанию — **27888** (TCP и UDP). Если он занят, выбирается свободный, и окно показывает используемый порт.

### Подключение к игре (клиент)

1. Нажмите **Мультиплеер**, введите адрес хоста в виде `IP:порт` (например, `203.0.113.5:27888`) и нажмите **Подключиться**.
2. Игра сама запустится, когда соединение будет установлено. **Отмена** закрывает лобби.

### Если подключиться не удаётся

Пройдите по шагам по порядку.

**1. Брандмауэр Windows / антивирус.** При первом запуске Windows спросит, разрешить ли доступ к сети: разрешите **`uc_launcher.exe`** и **`uc.exe`** (и TCP, и UDP, в частных и общедоступных сетях). Если вопрос не появился, добавьте правила вручную: _Безопасность Windows → Брандмауэр и защита сети → Разрешить работу с приложением через брандмауэр_. Брандмауэры сторонних антивирусов (ESET, Kaspersky и другие) требуют тех же правил. Это нужно сделать **обоим** игрокам.

**2. Автоматическое открытие портов (UPnP).** Для хоста лаунчер просит роутер пробросить порт. Это работает, только если в роутере включён UPnP. Если в окне написано _«Автопроброс недоступен»_, переходите к следующему шагу.

**3. Ручной проброс портов (на роутере хоста).**

1. Узнайте локальный адрес компьютера хоста (например, `192.168.1.10`; он показан в строке **Локальная сеть**). Лучше закрепить его резервированием DHCP в роутере.
2. Откройте веб-интерфейс роутера (обычно `192.168.0.1` или `192.168.1.1`) → _Port forwarding_ / _Виртуальный сервер_ / _NAT_.
3. Создайте правила, пробрасывающие **порт 27888, протоколы TCP и UDP**, на локальный адрес компьютера хоста и тот же порт.
4. Дайте другу ваш **внешний** IP-адрес (строка _Интернет_ в лобби или любой сайт «мой IP») и порт.

**4. Пробитие NAT (без изменения роутера).** Используйте, когда друг не может подключиться напрямую, а пробросить порт нельзя:

1. Друг (клиент) вводит `IP:порт` хоста и нажимает **Подключиться**. Если прямое соединение не удалось, в окне появится сообщение _«Подключиться не удалось»_ и собственный **внешний IP:порт** друга (он определяется автоматически; подождите несколько секунд). Друг **копирует его и отправляет хосту**.
2. Хост, не закрывая лобби, раскрывает раздел **Пробить NAT**, вставляет `IP:порт` друга в поле и нажимает **Пробить NAT**.
3. **Не закрывайте оба окна.** Клиент друга автоматически повторяет подключение, и игра запустится сразу после успешного соединения.

Пробитие NAT работает с большинством домашних роутеров. Оно не сработает, если у любой из сторон **симметричный NAT** (лаунчер предупредит об этом) или провайдер использует **CGNAT / двойной NAT** (в лобби будет сказано, что у роутера нет публичного IPv4-адреса). В этих случаях используйте проброс портов или VPN.

**5. VPN или виртуальная локальная сеть.** Если ничего не помогает (CGNAT, строгий провайдер), оба игрока ставят виртуальную сеть вроде ZeroTier, Tailscale, Radmin VPN или WireGuard и используют _виртуальный_ IP-адрес хоста в поле **Локальная сеть**. Проброс портов при этом не нужен.

**Что ещё проверить**

- Проверьте адрес и порт: они должны быть точно такими, как показывает лобби хоста.
- Хост должен держать окно лобби открытым, пока клиент не подключится.
- Подключение с того же компьютера или из той же домашней сети всегда идёт по **локальному** адресу.
- Если игра подключилась, но тормозит, компьютер, который не успевает, автоматически снижает общую частоту симуляции (60 → 30 Гц), а не разрывает соединение.

## Известные проблемы

- Ранняя сборка, проверена на одном ПК: на других видеокартах, драйверах и процессорах могут быть проблемы, которых автор не видел.
- Мультиплеер: см. выше. Возможны ошибки подключения, рассинхронизация и кратковременные зависания после сетевой задержки.
- Поддерживается только `RBUE08` (NTSC-U).
- Не все графические настройки совместимы друг с другом на всех видеокартах; неподдерживаемые затенены с указанием причины.
- Трассировка лучей пока охватывает только тени; остальные трассируемые эффекты не закончены.

Нашли что-то ещё? Расскажите: [Как сообщить о проблеме](#как-сообщить-о-проблеме).

## Как сообщить о проблеме

- **Баги и предложения:** [GitHub Issues](https://github.com/solleo95/reuc-recomp/issues) (для баг-репортов есть форма).
- **Вопросы, помощь и общение:** [Discord](https://discord.gg/njy2CqecyY).

Хороший отчёт содержит: **версию** порта (видна в лаунчере), вашу **видеокарту, драйвер и версию Windows**, какие графические настройки были включены (апскейлер, генерация кадров, трассировка лучей, HDR), как повторить проблему и скриншот или короткое видео, если проблема видна на экране. Релизные сборки не пишут файлы журналов; сборки из исходников пишут (папки `logs` и `debug` рядом с `uc.exe`), приложите их, если они у вас есть. Не прикладывайте никаких файлов игры.

## Сборка из исходников

Коротко: нужны Visual Studio Build Tools (C++), LLVM / `clang-cl`, CMake, Ninja, Python 3.10+, Vulkan SDK и **ваш собственный распакованный образ игры** (во время сборки `main.dol` транслируется в нативный код). Скопируйте [`local.env.example`](local.env.example) в `local.env`, укажите `UC_INSTALL_DIR` и запустите `build.bat`.
