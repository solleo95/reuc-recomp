## `get`

`settings.get(key)` returns `any`

Status: **implemented**, since API 1.0.

Current value of a declared setting; null for an unknown key.

- `key` (`string`): A key declared in mod.json.

Lua:

```lua
local scale = settings.get('damage_scale')
```

JavaScript:

```js
const scale = settings.get('damage_scale');
```

## `set`

`settings.set(key, value)` returns `bool`

Status: **implemented**, since API 1.0.

Changes a declared setting and saves it. Returns false (and changes nothing) for an unknown key or a value of the wrong type.

- `key` (`string`): A key declared in mod.json.
- `value` (`any`): New value; numbers are clamped to the declared range.

Lua:

```lua
settings.set('damage_scale', 2.0)
```

JavaScript:

```js
settings.set('damage_scale', 2.0);
```
