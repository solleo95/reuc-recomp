# weapon

_Generated by scripts/gen_mod_api.py from modding/api/uc_api.json. Do not edit._

Parameters of a weapon type: one record of the game's weapon table, addressed by its id 0 to 19 (uc.weapon(0)). Id 0 is the handgun (15 rounds, damage 10), 1 a shotgun (6 rounds), 2 a submachine gun (50 rounds); the table has 20 records and the other ids are not named yet (read capacity and damage to tell them apart). A change applies to every weapon of that type from the weapon's next shot or reload on. The game fills the table at boot and at mission starts, so the API remembers what a mod set and writes it again at the next game step whenever the game's value differs; it lasts until the game exits.

## `damage`

`uc.weapon(id).damage` (`float`, read/write)

Status: **implemented**, since API 1.0.

Damage per hit (per pellet for a shotgun): the handgun's 10 takes a zombie down in two hits. Checked in the game: with 100 a hit takes 100 off a zombie (the body, head and limb multipliers stay).

Lua:

```lua
uc.weapon(0).damage = uc.weapon(0).damage * 2
```

JavaScript:

```js
uc.weapon(0).damage *= 2;
```

## `fire_rate`

`uc.weapon(id).fire_rate` (`float`, read/write)

Status: **planned**, since API 1.0.

Shots per second. The weapon record has a rate field (1 for single shots, 10 to 15 for automatic weapons) but changing it did not change how fast the handgun shoots in automatic mode, so it is not exposed yet; how fast a held trigger shoots is fixed by the weapon's animation for now.

## `capacity`

`uc.weapon(id).capacity` (`int`, read/write)

Status: **implemented**, since API 1.0.

Magazine size, 0 to 999. The game reads it when a reload ends: with 30 set for the handgun a reload refills 30 rounds.

Lua:

```lua
uc.weapon(0).capacity = 30
```

JavaScript:

```js
uc.weapon(0).capacity = 30;
```

## `reload_time`

`uc.weapon(id).reload_time` (`float`, read/write)

Status: **implemented**, since API 1.0.

Reload duration in seconds of game time (1.0 for the handgun, 2.3 for a shotgun); 0.2 makes a handgun reload about seven times faster.

Lua:

```lua
uc.weapon(0).reload_time = 0.3
```

JavaScript:

```js
uc.weapon(0).reload_time = 0.3;
```

## `fire_mode`

`uc.weapon(id).fire_mode` (`string`, read/write)

Status: **implemented**, since API 1.0.

'semi' (one shot per press), 'auto' (shots repeat while the button is held) or 'burst'. 'auto' on the handgun was checked in the game (a held trigger fires about every 22 frames instead of once); 'burst' is the value the game's record 3 uses and its effect on other weapons is untested. Reading a value the table holds that has no name gives 'mode <number>'.

Lua:

```lua
uc.weapon(0).fire_mode = 'auto'
```

JavaScript:

```js
uc.weapon(0).fire_mode = 'auto';
```
