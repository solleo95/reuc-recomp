## Основы

Всё находится в глобальном **`uc`**:

| Область | Что это |
|---|---|
| `uc.player(slot)` | Игрок: магазин, повреждения, здоровье, переключатели (слот 1 или 2) |
| `uc.weapon(id)` | Тип оружия: урон, скорострельность, размер магазина (id от 0 до 19) |
| `uc.enemy(id)`, `uc.enemies` | Зомби: здоровье, позиция; список всех |
| `uc.game` | Часы миссии, пауза, звёзды, выдача оружия |
| `uc.camera` | Позиция и направление взгляда |
| `uc.input` | Кнопки и указатель так, как их видит игра |
| `uc.mem` | Сырая память игры |
| `uc.symbols`, `uc.guest` | Имена функций игры; их вызов |

Помимо `uc` есть глобальные имена мода: `on` (события), `hook` ([Хуки](hooks.md)), `settings` и `ui` ([Настройки и интерфейс](settings-and-ui.md)) и `log`.

Три правила действуют везде:

1. **Дескрипторы.** `uc.player(1)`, `uc.weapon(0)` и `uc.enemy(10)` возвращают **дескриптор**. Читайте и записывайте свойства через него: `uc.player(1).magazine = 15`.
2. **Для записи нужен `touches_gameplay`.** Мод, меняющий игру, должен сказать об этом в `mod.json`; читать можно всегда.
3. **Статусы.** Справочник помечает каждый член как `implemented`, `unverified` (работает, но подтверждён не во всех ситуациях) или `planned` (недоступен; использование - ошибка).

Ошибки API (отсутствующий игрок, неизвестный id, адрес вне памяти) - обычные ошибки скрипта; перехватывайте их через `pcall` (Lua) или `try/catch` (JavaScript), если ожидаете.

## Игроки

`uc.player(1)` - игрок 1, а `uc.player(2)` - игрок 2 в кооперативе. **Всегда проверяйте `present`**: игрока нет в меню и между миссиями.

| Член | Смысл |
|---|---|
| `present` | Есть ли игрок в текущей сцене (только чтение) |
| `magazine` | Патроны в заряженном магазине текущего оружия |
| `grenades` | Гранаты в запасе (один запас на обоих игроков) |
| `damage` | Шкала повреждений: 0 - цел, 50 - мёртв; запись 0 лечит |
| `health` | То же дробью: 1 - цел, 0 - мёртв (`health = 1 - damage / 50`) |
| `invulnerable` | Пока истинно, шкала повреждений сбрасывается каждый шаг |
| `infinite_ammo` | Пока истинно, магазин пополняется каждый шаг |
| `weapon` | Id оружия в руках игрока (только чтение) |
| `reserve` | Запас патронов удерживаемого оружия; `nil` для пистолета, у которого запас бесконечен (запись - ошибка) |
| `hits`, `critical_hits`, `objects_destroyed` | Счётчики экрана результатов для этой миссии |

```lua
local p = uc.player(1)
if p.present then
  p.health = 1                 -- полностью вылечить
  p.grenades = 9
  log.write('holding weapon ' .. p.weapon .. ', spare ' .. tostring(p.reserve))
end
```

`invulnerable` и `infinite_ammo` - **переключатели**: вы их включаете, а игра сама делает работу каждый шаг. Они выключаются сами, когда ваш мод останавливается.

## Оружие

`uc.weapon(id)` обращается к одной из 20 **записей** оружия (id от 0 до 19): пистолет - 0 и 19, дробовик - 1, пистолет-пулемёт - 2; все значения перечислены в [руководстве по патчам данных](data-patches.md#таблица-оружия). Изменение действует на всё оружие этого типа со следующего выстрела или перезарядки.

| Член | Смысл |
|---|---|
| `damage` | Урон за попадание (за дробинку у дробовиков), от 0 до 10000 |
| `fire_rate` | Выстрелов в секунду, от 0,05 до 60 |
| `capacity` | Размер магазина, от 0 до 999 (действует со следующей перезарядки) |
| `reload_time` | Секунд на перезарядку, от 0 до 1000 |
| `fire_mode` | `'semi'`, `'auto'` или `'burst'` |

```lua
local w = uc.weapon(0)
w.fire_mode = 'auto'      -- зажатый курок продолжает стрелять
w.fire_rate = 3
w.damage = w.damage * 2
```

Игра заполняет таблицу оружия при запуске и при каждом старте миссии; порт **записывает ваши значения снова, когда собственные значения игры отличаются**, на весь сеанс. Читайте исходные значения в `on_step` (а не в начале скрипта) и храните копию.

## Враги

Пока поддерживаются только **зомби**. Получите список, затем обращайтесь к отдельным врагам по `id`:

```lua
for _, e in ipairs(uc.enemies.list()) do
  -- e = { id, class, x, y, z, hp }
  if e.hp > 0 and e.x * e.x + e.z * e.z < 40 * 40 then     -- в пределах 4 м от начала координат (единицы по 10 см)
    uc.enemy(e.id).hp = 0                                  -- убить
  end
end
```

| Член `uc.enemy(id)` | Смысл |
|---|---|
| `hp` | Здоровье; зомби стартуют с 10-30; 0 или меньше - мёртв (актёр остаётся до конца волны) |
| `alive` | `hp > 0` (только чтение) |
| `head` | Цела ли голова (только чтение; отлетает при выстреле в голову) |
| `position` | `{x, y, z}` в единицах по 10 см, y вверх; запись мгновенно перемещает зомби |

Id действителен, **пока зомби не покинет сцену**; другой id или враг другого вида - ошибка. Чтобы реагировать на появление и смерть врагов, используйте [события](#события), а не опрос списка.

## Состояние миссии

| Член | Смысл |
|---|---|
| `uc.game.time` | Часы миссии в целых секундах (чтение или запись) |
| `uc.game.paused` | Истинно, пока открыто меню паузы игры (только чтение) |
| `uc.game.stars` | Деньги на улучшения, от 0 до 9999 (игра хранит их в данных сохранения) |

Часы и счётчики сохраняют последние значения вне миссии. `on_step` не выполняется, пока игра на паузе.

## Оружие в руках игрока

Выдайте оружие через `uc.game.give_weapon`, затем сделайте его удерживаемым через `uc.game.select_weapon`:

```lua
local index = uc.game.give_weapon(1, 2)        -- игрок 1, запись оружия 2 (пистолет-пулемёт); возвращает слот снаряжения
uc.game.select_weapon(1, index)                -- работает штатное переключение оружия игры: объект, магазин и HUD подстраиваются
```

`give_weapon(slot, id, key, magazine)`: `key` - ключ патронов (от 0 до 20, по умолчанию 0 - бесконечный запас как у пистолета, 7 использует запас патронов с ключом 7), а `magazine` - число патронов (по умолчанию ёмкость оружия). В снаряжении 16 слотов; оружие, которое у игрока уже есть, возвращает свой слот. `select_weapon` работает только из собственных событий игры (`on_step`, другие события, обработчики хуков), **но не** из окна настроек.

## Камера

Игра идёт «по рельсам»: оба игрока делят одну точку обзора, камеру.

| Член | Смысл |
|---|---|
| `uc.camera.position` | `{x, y, z}` глаза в единицах по 10 см (высота около 15) |
| `uc.camera.forward`, `right`, `up` | Единичные векторы вида |
| `uc.camera.view` | Матрица мир-в-вид, 12 чисел |

Когда сцены нет, они бросают ошибку. Проверка направления «этот враг передо мной?»:

```lua
local cam = uc.camera.position
local f = uc.camera.forward
local e = uc.enemies.list()[1]
if e then
  local dx, dy, dz = e.x - cam[1], e.y - cam[2], e.z - cam[3]
  local dist = math.sqrt(dx*dx + dy*dy + dz*dz)
  local ahead = (dx*f[1] + dy*f[2] + dz*f[3]) / dist     -- 1 - прямо перед собой, 0 - сбоку
  log.write(string.format('distance %.1f, ahead %.2f', dist, ahead))
end
```

## Ввод

То, что игра видит на **геймпаде игрока 1**.

| Член | Смысл |
|---|---|
| `uc.input.held` | Удерживаемые сейчас кнопки после модов: маска из A `0x800`, B `0x400` (курок), минус `0x10`, плюс `0x1000` |
| `uc.input.fire_held` | Курок удерживается |
| `uc.input.aim` | Указатель `{x, y}`, каждая координата от -1 до 1 (0, 0 - середина, y вниз) |
| `uc.input.force_held` | Кнопки, которые игра видит удерживаемыми, хотя игрок их не держит (маска; 0 сбрасывает) |
| `uc.input.block_held` | Кнопки, которые никогда не доходят до игры (маска; 0 сбрасывает) |
| `uc.input.aim_override` | Заставляет игру видеть указатель в `{x, y}`; `nil` возвращает его игроку |

```lua
uc.input.force_held = 0x400          -- курок удерживается вечно: автоогонь без нажатия игрока
-- ...
uc.input.force_held = 0              -- отпустить
```

Маски нескольких модов складываются; ваша снимается, когда ваш мод останавливается. Запись требует `touches_gameplay`.

## События

Обработчики, зарегистрированные через `on(имя, fn)`, выполняются в игровом потоке. Данные событий:

| Событие | Данные | Когда |
|---|---|---|
| `on_load` | нет | Мод стартовал |
| `on_unload` | нет | Мод останавливается |
| `on_step` | нет | Около 30 раз за игровую секунду; не во время паузы |
| `on_settings_changed` | `{ key }` | Изменилась объявленная настройка |
| `on_weapon_fired` | `{ slot }` | Игрок выстрелил |
| `on_reload` | `{ slot }` | Игрок начал перезарядку |
| `on_damage_taken` | `{ slot, amount }` | Шкала повреждений игрока выросла |
| `on_player_died` | `{ slot }` | Шкала повреждений достигла максимума (один раз за смерть) |
| `on_enemy_spawned` | `{ id, x, y, z, hp }` | Появился зомби (зомби, уже бывшие при старте мода или сцены, не считаются) |
| `on_enemy_killed` | `{ id, x, y, z }` | Здоровье зомби упало до 0 или ниже (один раз на зомби) |
| `on_enemy_headshot` | `{ id, x, y, z }` | Зомби отстрелили голову (один раз на зомби) |

Последние четыре события требуют `"api": "1.1"`. Изменения состояния обнаруживаются между шагами игры, поэтому два события в одном шаге приходят вместе.

```lua
on('on_enemy_headshot', function(e)
  uc.player(1).grenades = uc.player(1).grenades + 1     -- граната за каждый выстрел в голову
  log.write('head shot at ' .. e.x .. ', ' .. e.z)
end)
```

## Память

`uc.mem` читает и пишет память игры напрямую. Это самый мощный и самый опасный инструмент: неверная запись может уронить игру или испортить сохранение.

- **Адреса** - адреса Wii: MEM1 от `0x80000000` до `0x817FFFFF`, MEM2 от `0x90000000` до `0x93FFFFFF`. Адрес вне диапазонов - ошибка, а не падение.
- **Значения в игре хранятся в big-endian**; функции преобразуют сами.
- Функции: `read_u8`, `read_u16`, `read_u32`, `read_s8`, `read_s16`, `read_s32`, `read_f32`, `read_f64`, `read_bytes(address, length)` (до 4096 байт) и парные `write_*` (`write_bytes(address, list)`).
- Запись требует `touches_gameplay`.

```lua
local value = uc.mem.read_u32(0x80400000)      -- 0x80400000 - лишь пример допустимого адреса
uc.mem.write_f32(0x80400004, 1.5)              -- никогда не пишите по адресу, который не проверили в игре
```

Предпочитайте именованные члены: они сами находят нужные адреса. Память используйте, когда API не покрывает нужное, и **проверяйте каждый адрес** в игре, прежде чем на него полагаться. Такие объекты, как игрок, перемещаются от запуска к запуску; идите по указателям от неподвижных мест, а не копируйте адрес.

## Символы и вызов функций игры

`uc.symbols.lookup(name)` возвращает адрес именованной функции или переменной (у большинства функций имён нет), а `uc.symbols.name_of(address)` - обратное.

`uc.guest.call(address, {args})` **выполняет функцию игры** с целыми аргументами (до 8, в регистрах r3-r10) и возвращает её результат:

```lua
local record = uc.guest.call(0x8006C8C8, { 2 })     -- адрес записи оружия 2
```

Работает только из собственных событий игры (`on_step`, события, обработчики хуков), но не из окна настроек, а аргументы **не проверяются**: неверный указатель может уронить игру. Вызовы могут вкладываться на глубину до четырёх. Требует `touches_gameplay`.

## Рецепты

**Граната за каждый выстрел в голову** - см. [События](#события).

**Лечить, когда враг умирает**

```lua
on('on_enemy_killed', function()
  local p = uc.player(1)
  if p.present then p.health = math.min(1, p.health + 0.05) end
end)
```

**Двойной урон, пока у игрока меньше половины здоровья**

```lua
local base
on('on_step', function()
  if not base and uc.weapon(0).damage > 0 then
    base = {}
    for id = 0, 19 do base[id] = uc.weapon(id).damage end
  end
  local p = uc.player(1)
  if not base or not p.present then return end
  local factor = p.health < 0.5 and 2 or 1
  for id = 0, 19 do uc.weapon(id).damage = base[id] * factor end
end)
```

**Звёзды за долгую миссию**

```lua
on('on_step', function()
  if uc.player(1).present and uc.game.time == 120 then uc.game.stars = uc.game.stars + 100 end
end)
```

**Записывать в лог оружие игрока, когда оно меняется**

```lua
local last
on('on_step', function()
  local p = uc.player(1)
  if p.present and p.weapon ~= last then
    last = p.weapon
    log.write('now holding weapon ' .. last)
  end
end)
```

## Хорошие манеры

- **Делайте минимум на каждом шаге.** Все обработчики `on_step` всех модов делят 1 мс на шаг. Храните копию вместо пересчёта и делайте тяжёлую работу только при изменении.
- **Проверяйте `present`** перед тем, как трогать игрока.
- **Используйте события** вместо слежения за значениями самому.
- **Сообщайте, что вы меняете**, в описании мода и указывайте `touches_gameplay`.
- **Оставляйте игру такой, какой нашли.** Переключатели и значения оружия возвращаются автоматически; собственные записи в память отменяйте в `on_unload`.
- **Не зависьте от адресов** движущихся объектов.

## Версии API

У API есть версия `мажорная.минорная`, записываемая в `mod.json` как `"api"`. Новая минорная версия только **добавляет**; новая мажорная может менять. `"api": "1.0"` охватывает игроков, оружие, камеру, память, хуки (`pre`) и первые события; `"api": "1.1"` добавляет врагов, состояние игры, оружие в руках, ввод, события врагов и смерти, `hook.post`, `hook.replace` и вызов функций игры. Полный список - в [истории версий](../../api-changelog.md). Мод для более старой минорной версии продолжает работать.
